### Finding #5 — Doubled site suffix in 302 page titles [MEDIUM]

**Verified-evidence:**
- File: `apps/lizard-com/src/app/editorial-standards/page.tsx` (created by PR #2 batch 6)
- Line: `7`
- Observed:
```ts
title: 'Editorial Standards — How We Create Content | Lizard.com',
```
- `buildMetadata` in `packages/ui/src/components/SEOHead.tsx:67` appends `` | ${config.theme.siteName}``, producing rendered `<title>Editorial Standards — How We Create Content | Lizard.com | Lizard.com</title>`.

Counts per site (302 total):
- dog-com: 115/128 pages (90%)
- fish-com: 69/72 pages (96%)
- lizard-com: 47/49 pages (96%)
- saddle-com: 38/40 pages (95%)
- vets-co: 33/36 pages (92%)

**Recommended fix (one line, idempotent, in `packages/ui/src/components/SEOHead.tsx` line 67):**
```diff
- const fullTitle = `${title} | ${config.theme.siteName}`
+ const suffix = ` | ${config.theme.siteName}`
+ const fullTitle = title.endsWith(suffix) ? title : `${title}${suffix}`
```

Fixes all 302 pages in a single shared-component edit.

### Finding #11 — `/faq` page lacks aggregate FAQPage schema [MEDIUM]

**File:** `apps/dog-com/src/app/faq/page.tsx`
**Lines:** `127-135` (FAQAccordion call), `95` (`export default function FAQPage`)
**Observed:**
```jsx
<FAQAccordion items={...} includeSchema={false} ... />
```
Each FAQAccordion section is correctly opting out of inline schema (you can't have multiple FAQPage schemas on one page — that would be invalid), but no aggregate FAQPage schema was added at the page level. So the page renders with NO `application/ld+json` FAQ block at all.

**Expected per QC §2.10:** "FAQ on FAQ pages." Either:
- Add a single page-level `buildFAQSchema({ questions: [...all sections flattened...] })` + `SchemaScript`, or
- Add `includeSchema={true}` to one section if only one section matters (less ideal — would only emit that section's FAQs)

`buildFAQSchema` already exists in `@carloOS/ui` (`SEOHead.tsx:130-145`). Roughly 4 lines of new code.

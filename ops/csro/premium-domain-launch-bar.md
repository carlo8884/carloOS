# Premium Domain Launch Bar

**Set by Carlo 2026-06-01.** The credibility bar (trust/routes/CI) is necessary but NOT sufficient.
A priority site does not launch until it reads as a **premium category destination** — the obvious
owner of its one-word domain — not a generic article library.

**CSRO gate: if a site looks like a content site, it fails. No exceptions for the priority 8.**
**COO: NO content expansion on priority sites until Visual ships the premium first-screen standard
and applies it.** New pages only fill a CSRO-named gap.

Priority 8: Dog · Fish · Horses · Vets · PetFood · Saddle · Lizard · Ferret.

---

## The bar — a site PASSES only if ALL seven are true

1. **First-screen identity (2-second test).** Within two seconds of load — before any scroll — the
   hero communicates the category and the brand. A stranger shown only the first screen can name the
   domain. Distinct hero image/video, not a stock-template banner.

2. **Category ownership.** The first screen asserts "this is THE reference/control-center/buyer's
   guide for X," backed by visible proof presented as product features (scale, citations, methodology,
   primary-source data, original tools) — not buried in a footer or an About page.

3. **A product on the homepage, not a link to one.** A useful, interactive tool / workflow /
   diagnostic / comparison engine lives ON the first or second screen — something you DO, not an
   article you read. The homepage is a product surface, not a table of contents.

4. **Architecture reads as a product.** Hubs are framed as "what you can do here" (diagnose, compare,
   calculate, decide), not a flat list of post titles. Clear hierarchy, not a blog river.

5. **Distinct visual identity.** Typography, color, motion, and photography treatment are unique to
   THIS domain. No two priority sites feel interchangeable or templated. The domain owns a look.

6. **Memorability.** One signature element a visitor remembers and would describe to someone else —
   a hero tool, a data visualization, a striking visual motif, a workflow.

7. **The buyer test.** An acquirer shown the first screen believes this is a serious, defensible
   category asset/platform — not a content farm. Would survive a Tier-1 strategic-buyer demo.

A site is **premium-launch-ready** only when it clears all 7 PLUS the launch-polish checklist
(trust/routes/CI/imagery) PLUS IR PLUS advisor.

## Horses.com positioning — CSRO recommendation (gates Visual)

The bare premium domain **Horses.com** is most valuable as **the definitive general equine
authority** — a buyer of "Horses.com" expects the comprehensive horse destination, and breadth is
the domain's moat. **Recommendation: Horses.com = general equine authority; treat RACING INTELLIGENCE
(the #178 build) as a flagship sub-vertical / `/racing` product or its own brand — not the homepage
identity.** This keeps the flagship premium-general while preserving the racing asset and the
Equine-Network-aligned value. *Confirming with Carlo before Visual sets direction (acquisition call).*

## Process / sequence

1. **Visual produces ONE premium first-screen standard** — a reference design + spec (grid, hero
   system, homepage-tool pattern, type/color/motion tokens) that satisfies the 7 gates.
2. CSRO reviews the standard against this bar before it's applied.
3. Visual applies it to the priority 8 (Ferret + Saddle hero fixes fold into this pass).
4. **COO holds content expansion** until 1–3 land; then resumes only on CSRO-named gaps.
5. Each redesigned site re-runs: launch-polish checklist → premium bar (7 gates) → IR → advisor.

CSRO owns this bar; Visual owns execution; COO gates content; advisor is final.
